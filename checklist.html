工具

产品定型核验包

给定型会与售前共用的字段表。每一行都要能回到证据链接与负责人；未知项单独列出并指定风险签字人。

工具定型核验包

字段总表（复制用）

#字段填写说明四态证据链接负责人
1目标场景园区 / 数据中心 / AI Fabric…
2目标客户 / 拓扑规模、冗余、是否 RoCE
3目标型号 / ASIC含板卡版本
4目标 NOS / 版本 / 镜像社区或商业、授权方式
5SDK / SAI / 平台插件版本锁定方式
6硬件、光模块与 HCL实验室证据有无
7补丁 / CI / DUT / 回归加固过程追溯
8AI/DC 拓扑与拥塞验证PFC/ECN、封装路径
9升级 / 回退 / CVE / RMA窗口与责任
10已知限制与风险签字人未知项必须有主

使用规则

  1. 四态只能填：有值 / 待复核 / 未披露 / 抽取失败。
  2. 「有值」必须有可打开的证据链接，且链接指向的版本与第 3、4 行一致。
  3. 定型会纪要中，未知项单独列表，不混入「已支持」统计。
  4. 基线哈希变化后，相关行自动标复核。
提醒：这张表的目的是减少会后扯皮，不是增加填表工作量。字段不全的行宁可标未知，也不要空白通过。

动手任务验收标准

  • 复制表结构并填入真实或练习项目各 1 行完整样例
  • 未知项均有 Owner

自测题（点击展开答案）

自测 1：核验包 10 字段中哪些最容易空着？
证据链接、负责人、已知限制与风险签字人——空着的行不能算通过。
自测 2：四态列允许留空吗？
不允许。必须是有值/待复核/未披露/抽取失败之一。
自测 3：基线哈希变化后相关行如何处理？
自动标复核，重新核对后再改四态，不得沿用旧「有值」。

建议：正确率 ≥ 80% 再进入下一页。培训组织者可按此判分。
